Settings menu — regrouping options

The current root menu has 8 items, two of which are inline shortcut recorders and one a one-shot size reset. These mockups explore consolidating them. Everything is clickable — sub-pages, modals, submenus and the key recorders all work (Esc cancels recording / closes a modal, ⌫ on an empty search goes back).

Glyphs: ⌘ command · ⇧ shift · ⌥ option · ⌃ control · ↩ return
